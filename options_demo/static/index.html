How to read this report

Calls and puts use separate Isolation Forest models with robust median/IQR feature scaling. The synthetic demo trains on a separate generated baseline; TWS mode fits the current snapshot only. Wide spreads, missing open interest, incomplete Greeks and thin activity affect interpretation.

Volume does not reveal buyer versus seller intent. Volume × midpoint × 100 is only an approximate notional, not observed trade premium. Rule-based reasons describe a contract; they are not model feature attributions.
